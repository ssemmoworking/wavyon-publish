# Wavyon Flutter Draft

This folder contains a Flutter/Dart starter converted from the existing React draft UI.

What is included:
- Bottom-tab mobile shell for `Home`, `Trip`, `Community`, `Chat`, and `My`
- Shared theme, cards, badges, chips, and list patterns
- Sample data in Dart
- Route scaffolding for the sub-screens found in the React draft

Notes:
- This is a design-oriented starter, not a production-complete app.
- Text that appeared corrupted in the original source was normalized into simple English placeholders so implementation can continue cleanly in Flutter.
- Image-heavy areas currently use placeholders so the project can run without asset migration first.

To run:

```bash
flutter pub get
flutter run
```
